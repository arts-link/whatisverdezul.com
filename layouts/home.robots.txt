{{- /* Preview deploys must not be crawlable. Vercel sets VERCEL_ENV to
       "preview" on branch/PR deployments and "production" on the real one, so
       an explicitly non-production value blocks everything.

       Polarity matters: UNSET means permissive. A local `hugo` has no
       VERCEL_ENV and must keep producing the same robots.txt production does,
       otherwise the file can't be checked locally. Only an explicit
       non-production Vercel value flips it.

       Requires '^VERCEL_' in [security.funcs] getenv in hugo.toml. Remove it and
       the build FAILS outright — "access denied: VERCEL_ENV is not whitelisted"
       — rather than quietly guessing. That hard coupling is deliberate: the two
       files cannot drift apart without someone noticing. */ -}}
{{- $vercelEnv := getenv "VERCEL_ENV" -}}
{{- if and $vercelEnv (ne $vercelEnv "production") -}}
# Preview deployment ({{ $vercelEnv }}) — not the live site.
#
# Blocked so preview copies can't be indexed and compete with
# www.whatisverdezul.com. Preview URLs are unguessable but they leak through
# pull request links and chat unfurls, which is enough.
#
# The production build of this same file is permissive — see
# layouts/home.robots.txt.

User-agent: *
Disallow: /
{{ else -}}
# robots.txt for whatisverdezul.com
#
# Nothing is blocked. Two decisions below look like oversights, so they are
# written down rather than left to be "helpfully" corrected later.
#
# 1. /admin/ is NOT disallowed, on purpose.
#    static/admin/index.html already carries <meta name="robots" content="noindex">.
#    Disallowing the path would stop crawlers FETCHING it, which means they
#    would never read that noindex — and a robots-blocked URL can still be
#    indexed URL-only from an external link, with no way left to suppress it.
#    Allowing the crawl is what makes the noindex enforceable. Crawl budget is
#    irrelevant on a site this size.
#
# 2. AI crawlers are deliberately unblocked.
#    Being cited by ChatGPT, Perplexity and AI Overviews is an explicit goal
#    (see docs/for-the-band/site-handoff.md, "Getting found"), and the site
#    ships an llms.txt for exactly that. No per-bot Allow: rules — the
#    wildcard below already permits them and a list of redundant blocks would
#    only rot.

User-agent: *
Allow: /

Sitemap: {{ "sitemap.xml" | absURL }}
{{ end -}}
